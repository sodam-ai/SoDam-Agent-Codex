# 로컬 생성 운영

실제 JSON·필수 노드·모델 파일·입력·출력·권리를 확인한다. 원본 워크플로우와 모델을 보존하고 분리 후보로 업데이트한다. 카탈로그/설치/연결/로드/큐/파일/기술 검사/시청·청취를 별도로 확인한다. 포트·프레임 규칙·특정 PC 경로를 전역화하지 않는다. 실패 원인과 재사용 가능한 설정을 기록한다.

사용자·상위 지시와 원본 보존을 우선한다. 현재 권한·도구별 쓰기 게이트를 따르며 내부 관점과 독립 검증을 구분한다.
