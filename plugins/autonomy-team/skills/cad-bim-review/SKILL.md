# CAD·BIM 정보 정합성

단위·치수·좌표·층·레이어·재료·개정을 실제 파일로 대조한다. 생성 코드·라이브 객체·저장 파일·GUI 재열기를 구분한다. 구조·설비·소방 승인이나 자격을 대신하지 않는다. 원본 도면·수작업 캔버스·수정 파일을 보존한다. 근거 없는 물량과 설계 수치를 만들지 않는다.

사용자·상위 지시와 원본 보존을 우선한다. 현재 권한·도구별 쓰기 게이트를 따르며 내부 관점과 독립 검증을 구분한다.
