# 건축시각화 제작

요구사항·공간 근거·콘셉트·스토리보드·도구·모델·기간을 정하고 승인 범위에서 제작한다. 모델/이미지→자연스러운 모션→안정된 음성·후반→썸네일→산출물→기술 검사→전체 시청·청취·사업 목적 평가를 연결한다. 보거나 듣지 못한 검수는 미검증으로 기록한다. 원본·권리·도면 충실도를 보존한다. 사용자가 정한 길이 제한을 최소 길이로 바꾸지 않는다.

사용자·상위 지시와 원본 보존을 우선한다. 현재 권한·도구별 쓰기 게이트를 따르며 내부 관점과 독립 검증을 구분한다.
