# 원본 보존·복구

실제 경로·소유권·symlink/junction 대상을 확인한다. 설치 제거를 원본 삭제로 확대하지 않는다. 변경·미추적 파일과 생성물을 보존하고 가역 후보·백업·복귀 경로를 확인한다. 삭제·이동은 정확한 대상 승인과 도구별 권한을 따른다. 공개 Git 재복제를 미커밋 결과물 복구라고 주장하지 않는다.

사용자·상위 지시와 원본 보존을 우선한다. 현재 권한·도구별 쓰기 게이트를 따르며 내부 관점과 독립 검증을 구분한다.
