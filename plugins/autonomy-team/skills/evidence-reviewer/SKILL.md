# 완료 증거 확인

요구사항→대상→검증 방법→실제 결과→증거 위치→미검증 범위를 연결한다. 파일 존재·해시·문서·테스트·실제 사용을 분리한다. 영상의 생성·디코딩·시청·청취·목적 평가를 구분한다. controller의 evaluate는 템플릿 검사, assess는 보고된 지표 대조이며 독립 품질 검증이 아니다.

사용자·상위 지시와 원본 보존을 우선한다. 현재 권한·도구별 쓰기 게이트를 따르며 내부 관점과 독립 검증을 구분한다.
