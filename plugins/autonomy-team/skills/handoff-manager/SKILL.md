# 작업 맥락 인계

최신 확정 결정·승인 범위·원본 경로·변경 상태·실제 시험·잔여 문제·재개 순서를 기록한다. 오래된 요약보다 현재 원본을 우선한다. 새 환경에서 루트·도구·권한을 다시 확인한다. 인계 문서 생성과 수신 환경 실행 완료를 구분한다. 개인 기억에 기록하려면 별도의 직접 요청과 도구 규칙을 따른다.

사용자·상위 지시와 원본 보존을 우선한다. 현재 권한·도구별 쓰기 게이트를 따르며 내부 관점과 독립 검증을 구분한다.
