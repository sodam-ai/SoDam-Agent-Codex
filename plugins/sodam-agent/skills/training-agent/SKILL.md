# 직원 가르치기

이 작업은 모델 재학습이 아니라 SKILL.md 업무 지시서를 수정하는 것입니다. 사용자 제작 스킬만 대상으로 현재 지침을 읽고, 추가 또는 교체할 행동을 확인합니다. 플러그인 제공 스킬은 직접 고치지 말고 먼저 사용자 스킬로 복사하도록 안내합니다.

원본을 백업하고 변경 전후 차이를 보여준 뒤 승인을 받습니다. 사용자가 명시하지 않은 이름·설명·권한 경계는 유지하고 비밀은 기록하지 않습니다. 수정 후 파일을 다시 읽고 스킬 검증을 실행합니다.

## 지속 개선과 구분 (0.2.0)

이미 직접 승인한 변경 범위는 반복 승인으로 지연하지 않습니다. 새 범위·권한·비용·손실 영향이 생기면 그 차이만 확인합니다. 성공 답변을 학습 근거로 쓰지 말고 실제 산출물·실패·사용자 수정과 비교 결과를 사용합니다.
자동 모드는 autonomy-team의 experience-improver와 컨트롤러의 후보·pilot·쌍별 비교·복귀를 사용합니다. 기존 사용자 스킬·개인 기억·전역 설정을 자동 변경하지 않습니다. 내부 검토·템플릿 시험·모델 재학습·독립 품질 검증을 구분합니다.
