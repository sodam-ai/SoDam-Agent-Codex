# 직원 골라오기

설치된 팀의 `skills/<role>/SKILL.md`를 정본으로 읽습니다. 사용자가 원하는 역할과 새 이름을 확인하고, 이름은 소문자·숫자·하이픈 1~50자로 검증합니다. 프로젝트 또는 개인 스킬 위치를 선택하게 하고, 충돌 시 덮어쓰기 전에 기존 파일을 백업하고 구체적인 승인을 받습니다.

복사 시 원문의 목적과 제약은 보존하고 사용자가 요청한 규칙만 분명히 추가합니다. 미리보기 승인 후 적용하고, 다시 읽기와 검증을 수행합니다.
