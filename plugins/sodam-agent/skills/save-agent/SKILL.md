# 직원 저장·재사용

프로젝트와 개인 스킬 폴더에서 사용자 제작 스킬을 찾고 원본 전체를 읽습니다. 개인 사용은 `$CODEX_HOME/skills/<name>`(미설정 시 `~/.codex/skills/<name>`), 보관은 사용자가 지정한 폴더를 사용합니다.

대상 경로와 복사 계획을 미리 보여주고 승인을 받습니다. 같은 이름이 있으면 기존 내용을 백업한 뒤 별도 덮어쓰기 승인을 받습니다. 비밀 포함 여부를 검사하고, 복사 후 파일 해시 또는 내용 비교와 스킬 검증을 수행합니다.
