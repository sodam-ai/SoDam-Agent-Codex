# 새 직원 만들기

사용자에게 이름, 하는 일, 작업 범위, 행동 규칙을 한 번에 하나씩 확인합니다. 이름은 소문자·숫자·하이픈만 허용하고 1~50자로 제한합니다.

프로젝트 직원은 `.agents/skills/<name>/SKILL.md`, 개인 직원은 `$CODEX_HOME/skills/<name>/SKILL.md`(미설정 시 `~/.codex/skills/<name>/SKILL.md`)에 둡니다. 기존 파일은 읽고, 변경 전 정확한 경로와 전체 미리보기를 보여준 뒤 사용자의 승인을 받습니다. 비밀이나 토큰은 쓰지 않습니다.

SKILL.md에는 `name`, 구체적인 자동 선택 조건을 담은 `description`, 짧고 실행 가능한 본문을 작성합니다. 생성 뒤 파일을 다시 읽고 스킬 검증기를 실행해 결과를 보고합니다.

## 자동 생성과 구분 (0.2.0)

현재 요청에 이름·목적·범위·승인이 충분하면 같은 정보를 다시 질문하지 않습니다. 직접 승인한 가역적 생성은 구체적인 결과를 만들고 검증하며 진행합니다. 미확정 정보가 실제 결과를 바꿀 때만 필요한 질문을 합니다.
반복 역량 부족의 자동 생성·시험 적용은 autonomy-team의 agent-builder와 프로젝트 컨트롤러를 사용합니다. 기존 스킬을 덮어쓰지 않고 별도 registry에서 후보·pilot·효과 미검증을 구분합니다. 파일 생성·스킬 선택·실제 도구 실행·품질 확인을 각각 보고합니다.
