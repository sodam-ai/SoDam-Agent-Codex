# 직원 제거

프로젝트 `.agents/skills`와 개인 Codex 스킬 폴더에서 사용자 제작 스킬만 후보로 보여줍니다. 설치된 플러그인 내부 파일은 직접 삭제하지 말고 플러그인 제거 절차를 안내합니다.

대상 이름과 실제 경로를 검증하고, 원본 폴더를 복구 가능한 `.bak` 사본으로 보존합니다. 삭제 대상과 백업 위치를 표시한 뒤 사용자의 명시적 최종 승인을 받아 그 스킬 폴더만 제거합니다. 제거 후 대상 부재와 백업 존재를 확인합니다.
