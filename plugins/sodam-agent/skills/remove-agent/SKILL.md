# 직원 제거

프로젝트 `.agents/skills`와 개인 Codex 스킬 폴더에서 사용자 제작 스킬만 후보로 보여줍니다. 설치된 플러그인 내부 파일은 직접 삭제하지 말고 플러그인 제거 절차를 안내합니다.

대상 이름과 실제 경로를 검증하고, 원본 폴더를 복구 가능한 `.bak` 사본으로 보존합니다. 삭제 대상과 백업 위치를 표시한 뒤 사용자의 명시적 최종 승인을 받아 그 스킬 폴더만 제거합니다. 제거 후 대상 부재와 백업 존재를 확인합니다.

## 원본 보존 보강 (0.2.0)

대상 자체와 부모의 symlink/junction 여부·링크 대상·소유권·변경/미추적 파일을 먼저 확인합니다. 설치 링크 제거는 링크만 대상으로 하고 링크 원본을 백업·재귀 삭제 대상으로 따라가지 않습니다. 설치 제거 요청이나 프로그램 종료 동의를 원본 프로젝트 삭제 승인으로 해석하지 않습니다. 소유권을 확인하지 못한 파일은 보존합니다. 공개 저장소 재복제를 미커밋·생성 파일 복구로 표현하지 않습니다.
컨트롤러 생성 역할은 autonomy-team rollback으로 비활성화합니다. 개인 스킬·원본 폴더를 제거할 권한은 자동화 승인에서 생기지 않습니다.
