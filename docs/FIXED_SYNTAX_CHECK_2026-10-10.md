# 제한된 문법 검사와 실제 업무 재사용

개발 정본은 SoDam-Agent-Codex이며 Context-Eng 복사본은 검증 대상이다. 예약 작업은 생성하지 않았다.

## 변경

check_node_syntax MCP와 syntax-check CLI를 추가했다. 승인된 프로젝트의 mjs/cjs 1~4개를 최대 256KiB씩 안전하게 읽고 해시를 계산한다. 고정 Node 문법 파서에 같은 스냅샷을 표준입력으로 전달한다. 파일당 5초 제한, shell 미사용, preload 환경 미상속, 소스 실행 없음, 파서 출력 반환 없음이다. 잘못된 입력은 실행 전에 거부한다. 실패 결과는 실제 종료값과 함께 실패로 반환한다.

## 검증

node test/syntax-checker.mjs: 8개 그룹 통과. node test/mcp.mjs: 18개 그룹 통과. npm test: 18개 테스트 파일 통과. npm run validate: 12개 플러그인, 56개 스킬, 24개 매니페스트, 외부 의존성 0.
정상·실패·권한 부재와 만료·경로 탈출·중복·하드링크·연결 디렉터리·바이트 경계·비정상 UTF8·실행 부작용 방지·환경 옵션 주입 차단을 검사했다. 파서의 실제 시간 초과와 메모리 압박 상황은 미실행이다. 별도 lint/typecheck/build 명령은 package.json에 없다.

## 실제 업무 적용

이번 독립 요청의 dispatch가 이전 실제 업무 교훈 event-24f7a92581c875f3e835057e12d1cac8을 반환했다. 종료 정보, 정본과 설치본 일치, 실행 프로세스 최신 여부를 구분하는 절차를 이번 개발과 검증에 적용했다. 자동 회상 및 이번 업무 적용은 확인했으며 장기 품질 향상은 아직 판단하지 않는다.

## 한계

문법 검사는 단위 테스트·빌드·의미 품질을 대체하지 않는다. plain Bash 결과는 unknown으로 남긴다. 새 로컬 MCP 검사와 Desktop의 기존 MCP 연결은 별개다. 설치 후 Desktop에서 current 및 승인 유효를 다시 확인해야 한다. 훅 정의와 Codex 설정은 변경하지 않았다.

## 최종 설치 및 복사본 재검증

문서 보강 후 AUTONOMY 사본 불일치를 발견하여 원문과 동기화한 뒤 npm test 전체 18파일과 validate를 다시 통과했다. 설치 위치 3곳의 런타임 및 안내 18파일 해시가 정본과 일치하며 기존 파일 백업을 보존했다. 훅 정의는 변경하지 않았다. 테스트 복사본에서도 새 검사 8그룹 및 MCP 18그룹이 통과했다. 새 설치본 로컬 MCP로 실제 변경 파일 4개 문법 검사 및 승인 유효·workEligible을 확인했다. 실행 fingerprint는 223b6fc8af3d69ee63c65ed0de9e609aade110ca87191967099b2e25e991bbd1이다.

연결된 Desktop MCP는 설치 직전 current였고 최종 설치 후 changed로 판정됐다. 종료나 권한 변경 없이 새 모듈을 기존 프로세스에 주입할 수 있는 도구는 제공되지 않았다. 설치 묶음을 고정했으며 추가 런타임 수정 없이 다음 재연결에서 위 fingerprint 및 새 도구를 확인한다. 기존 unknown은 보존했다. 이번 작업이 장기 개선을 입증하지는 않는다.
