# 공개·배포·상업적 사용 가이드

수정일: 2026-10-10. 문서·파일 검사 안내이며 개별 법률 자문이나 권리 보증이 아닙니다. 영어 대응 문서: [LEGAL_AND_DISTRIBUTION.en.md](LEGAL_AND_DISTRIBUTION.en.md).

## 확인한 사실

- 프로젝트 선언은 Apache-2.0입니다. `LICENSE`는 Apache Software Foundation의 공식 Apache License, Version 2.0 본문과 공백 정규화 비교에서 일치합니다. 영문 원문이 기준입니다. 추가 제한 조건을 LICENSE에 넣지 않았습니다.
- 기존 권리자 표기는 Copyright 2026 SoDam AI Studio입니다. 표기를 보존했지만 기여자 계약이나 원본의 권리 양도 증빙까지 입증한 것은 아닙니다.
- `NOTICE`는 출처 고지이며 라이선스 조건을 추가하거나 변경하지 않습니다. 이 배포본에 포함되므로 적용되는 고지를 재배포본에도 읽을 수 있게 보존합니다. 모든 Apache 프로젝트가 새 NOTICE를 반드시 만들어야 한다는 뜻은 아닙니다.
- 최상위 package.json에는 직접 dependencies/devDependencies가 없습니다. lockfile·node_modules·assets·public·이미지·폰트·음원·영상은 공개 후보 파일 목록에서 발견하지 않았습니다. 스킬 문서·프롬프트·테스트 예시는 포함됩니다.
- web-app-team과 research-team은 @upstash/context7-mcp@4.1.1을 npx로 별도 실행합니다. 해당 버전 npm 메타데이터와 공식 저장소 LICENSE는 MIT입니다. MIT 고지를 보존하는 경우 Apache-2.0과의 결합을 일률적으로 금지하는 조건은 확인되지 않았습니다. 현재 배포본에 그 패키지를 번들하지 않습니다. 전체 실행 시 의존성 트리·다른 MCP·서비스 약관은 미확인입니다.

## 어디까지 사용할 수 있나요?

| 용도 | 안내 |
|---|---|
| 개인·회사 내부 사용, 공부, 교육 자료 | Apache-2.0 적용 자료를 조건에 따라 사용할 수 있습니다. 교육 자료 재배포에도 고지를 지킵니다. |
| 수정·복제·포크 | 가능합니다. 변경 파일에 변경 사실을 표시하고 해당 원본 고지를 보존합니다. |
| 재배포·판매·고객사 납품 | 가능합니다. LICENSE 사본과 적용되는 NOTICE·출처 고지를 전달하고 변경 표시를 보존합니다. 고객 자료와 계약 권리는 별도 확인합니다. |
| 유료 서비스 운영 | Apache-2.0 자체는 상업 운영을 금지하지 않습니다. 서비스 약관·개인정보·고객 계약·API 비용을 별도로 확인합니다. |
| 수정 코드 비공개 | Apache-2.0 자체는 수정 소스의 공개를 일반 의무로 요구하지 않습니다. 재배포 조건과 함께 포함한 다른 라이선스는 별도 적용됩니다. |
| 외부 API 결과·AI 생성물·이미지·폰트·모델 | 이 프로젝트의 라이선스가 자동 적용되지 않습니다. 제공자 정책·입력 권리·출처·유사 저작물 침해 가능성·최종 검수를 직접 확인합니다. |

## 하면 안 되는 일과 책임 범위

- 원본 고지를 제거하거나 타인의 코드·콘텐츠를 자신의 독점 저작물이라고 주장하지 않습니다. 상표·로고·캐릭터 사용이나 공식 제휴를 Apache-2.0으로 정당화하지 않습니다.
- 고객 내부 자료·개인정보·접속 키·비공개 API·상세 실행 기록을 공개 샘플이나 교훈으로 게시하지 않습니다. 시험의 더미 값도 실제 계정으로 교체하지 않습니다.
- AI가 만든 코드·문서·이미지·콘텐츠의 저작권 성립, 독점권, 출처 또는 상업적 안전성을 보장하지 않습니다. 최종 사용 전에 생성 서비스 정책, 입력 권한과 유사성·침해 위험을 검토합니다.
- 보증 없음과 책임 제한은 LICENSE 제7~9조 및 적용 법률·별도 계약에 따릅니다. 고의·중과실 등 법률상 예외까지 면책되는 것은 아닙니다. 추가 보증은 자신의 책임으로만 약정합니다.
- 특허 허락은 기여물에 관련된 제한 범위이며 특정 특허 소송에서 종료될 수 있습니다. 모든 특허 위험을 해소하는 보장은 아닙니다.

## 공개·납품 전 우선순위

**Must Have:** 배포할 파일과 LICENSE/NOTICE 포함, 변경 표시, 비밀·개인정보 제외, 실제 입력 자료 사용 권한 확인, 외부 패키지를 번들한다면 버전별 라이선스·고지 확인. CHECKPOINT.md, .sodam-agent, outputs의 로컬 기록·백업, 캐시·키·환경 설정은 배포 대상에서 제외합니다. .gitignore는 이미 추적한 파일을 제거하지 않으므로 git ls-files와 staged diff도 확인합니다.

**Should Have:** 회사·고객 납품 계약, AI 제공자·API의 상업 요금과 데이터 처리 조건, 기여자·원본 권리 증빙, 상표 표현을 검토합니다. 미해결 자료가 새로 발견되면 해당 자료를 공개하기 전에 권한을 확인합니다.

**Could Have:** 실제 배포 의존성에 대한 SBOM·파일별 권리 대장과 정기 재점검을 추가합니다. 현재 의존성 없는 저장소에 검사기를 무조건 설치하지 않습니다.

## 법무/전문가 검토 필요

원본 SoDam-Agent와 기여자의 권리 귀속·라이선스 부여 권한, 상표 사용, 관할 지역의 AI 생성물·개인정보 규정, 고객 계약의 보증·배상·비밀유지 조건은 이 파일 검사만으로 확정할 수 없습니다. 실제 고객 데이터, 제3자 콘텐츠나 추가 패키지 도입 시 다시 검토해야 합니다. 일반적인 공개 소스 변경의 기술 검사와 개별 납품의 권리 보증을 구분합니다.
