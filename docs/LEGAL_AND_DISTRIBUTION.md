## 확인한 사실

- 프로젝트 선언은 Apache-2.0입니다. `LICENSE`는 Apache Software Foundation의 공식 Apache License, Version 2.0 본문과 공백 정규화 비교에서 일치합니다. 영문 원문이 기준입니다. 추가 제한 조건을 LICENSE에 넣지 않았습니다.
- 기존 권리자 표기는 Copyright 2026 SoDam AI Studio입니다. 표기를 보존했지만 기여자 계약이나 원본의 권리 양도 증빙까지 입증한 것은 아닙니다.
- `NOTICE`는 출처 고지이며 라이선스 조건을 추가하거나 변경하지 않습니다. 이 배포본에 포함되므로 적용되는 고지를 재배포본에도 읽을 수 있게 보존합니다. 모든 Apache 프로젝트가 새 NOTICE를 반드시 만들어야 한다는 뜻은 아닙니다.
- 최상위 package.json에는 직접 dependencies/devDependencies가 없습니다. lockfile·node_modules·assets·public·이미지·폰트·음원·영상은 공개 후보 파일 목록에서 발견하지 않았습니다. 스킬 문서·프롬프트·테스트 예시는 포함됩니다.
- web-app-team과 research-team은 @upstash/context7-mcp@4.1.1을 npx로 별도 실행합니다. 해당 버전 npm 메타데이터와 공식 저장소 LICENSE는 MIT입니다. MIT 고지를 보존하는 경우 Apache-2.0과의 결합을 일률적으로 금지하는 조건은 확인되지 않았습니다. 현재 배포본에 그 패키지를 번들하지 않습니다. 전체 실행 시 의존성 트리·다른 MCP·서비스 약관은 미확인입니다.

**Must Have:** 배포할 파일과 LICENSE/NOTICE 포함, 변경 표시, 비밀·개인정보 제외, 실제 입력 자료 사용 권한 확인, 외부 패키지를 번들한다면 버전별 라이선스·고지 확인. CHECKPOINT.md, .sodam-agent, outputs의 로컬 기록·백업, 캐시·키·환경 설정은 배포 대상에서 제외합니다. .gitignore는 이미 추적한 파일을 제거하지 않으므로 git ls-files와 staged diff도 확인합니다.

**Should Have:** 회사·고객 납품 계약, AI 제공자·API의 상업 요금과 데이터 처리 조건, 기여자·원본 권리 증빙, 상표 표현을 검토합니다. 미해결 자료가 새로 발견되면 해당 자료를 공개하기 전에 권한을 확인합니다.

**Could Have:** 실제 배포 의존성에 대한 SBOM·파일별 권리 대장과 정기 재점검을 추가합니다. 현재 의존성 없는 저장소에 검사기를 무조건 설치하지 않습니다.
