# 실제 업무 기반 개선 보강 결과 — 2026-10-11

## 목적과 위치
개발 정본은 SoDam-Agent-Codex D 원본이다. D 테스트 Context-Eng는 실제 문서 작업·검증 대상이며 Agent 개발 정본이 아니다. 이전 교훈의 요구사항 대조·증거 경계·원본 보존 절차를 이번 구현 검토에 적용했다. 모든 과거 채팅 원문을 새로 조사했다거나 미래 무오류를 보장하지 않는다.

## 구현 및 재현
변경: plugins/autonomy-team/runtime/{engine,learning,bridge,workflow}.mjs, test/work-learning.mjs, 한국어·영어 README.md/HTML, docs/AUTONOMY.md, autonomy-team/reference/operating.md 및 skills/autonomy-team/SKILL.md.
기존 실패 중심 생성만으로는 성공 업무에서 기존 확정 역할의 개선을 제안할 경로가 부족했다. 개선 표시가 있는 검증 교훈 두 건을 제한된 후보로 연결했다. 기본 팀은 프로젝트 전용 역할로 보완하고 설치 팀 원본을 자동 수정하지 않는다. 기존 generated 역할은 절차 증거와 다른 개선안을 요구한다.
추가 보강 과정의 조건부 역할 생성 회귀를 재현했다. 생성 전 맥락 필터가 기존 조건부 생성까지 막은 것이 원인이었다. 생성 흐름을 복구하고 실제 선택 조건은 유지하여 전체 시험으로 재검증했다. 편집 도우미 문법 오류도 수정했다. 실패한 검사 이력을 숨기거나 성공으로 재분류하지 않았다.

## 검증 범위와 안전
- npm run validate: 플러그인 12개, 스킬 56개, 매니페스트 24개, 외부 의존성 0.
- npm test: package.json의 18개 스크립트 모두 종료 코드 0. 작업 학습 46개 그룹. 권한·만료·변조·역할 한도·정상·실패·복구·연결·실제 stdio MCP 시험 포함.
- README 한국어·영어 Markdown과 HTML 내 원본 바이트·해시 일치 및 운영 문서 복제 일치 검사 통과. 새 절의 공개 내용도 각각 확인.
- 추가 lint/typecheck/build 스크립트 없음: 별도 미실행. 웹 UI·로그인·결제·DB 서비스는 이 플러그인 대상 기능이 아니며 브라우저 사용 시험 미실행.
- 외부 유료 API·예약 작업·개인 메모리·볼트·Codex 설정·AGENTS.md·모델 가중치·프로젝트 승인 변경 없음.
- 기술 시험의 이벤트는 격리된 합성 입력이며 실제 업무 경험으로 저장하지 않았다. 시험 결과 realModelExecution=false를 유지한다.
- 기존 스킬 템플릿은 새 개선 표시가 없는 한 유지한다. 설치 변경 파일만 백업했다. 이번 기술 통과를 실제 신규 역할 효과나 독립 의미 품질 인증으로 확대하지 않는다.

## 남은 정확한 작업
기존 Desktop MCP는 파일 교체 후에도 이전 프로세스이므로 재연결이 필요하다. 제공된 도구에는 재연결 API가 없어 새 로컬 MCP 검사와 기존 Desktop 상태를 구분한다. 재연결 후 inspect_runtime의 currentSourceMatchesStartup=true와 승인 유효를 확인한다. 이후 실제 업무에서 새 개선 후보를 사용·검수하고 서로 다른 실제 후속 과제의 비교 자료로 효과를 판단한다. turnKey를 만들거나 다른 요청의 ID를 빌려 검증하지 않는다. 예약 작업을 추가하지 않는다.
