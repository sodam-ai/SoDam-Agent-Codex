# 역할 상태·교훈 선택·복구 검수 — 2026-10-11

개발 수정은 SoDam-Agent-Codex 정본, 실제 증거 확인은 승인된 D 테스트 복사본에서 수행했다. 예약 작업과 Codex 설정 변경은 없다. 다른 세션과 실행 중인 프로세스는 종료하지 않았다.

## 순서별 결과
1. 역할 상태: pilot/confirmed 선택, 품질 실패 비활성화, 이전 역할 복귀, 새 근거 기반 후속 버전 생성 시험 통과. 맥락 불일치 시 기존 역할 평가·대체 경로를 막았다. 임의 강제 재활성화나 호스트 에이전트 자동 설치를 구현했다고 주장하지 않는다.
2. 교훈 선택: 손상된 교훈의 절차 누락이 전체 recall을 중단하는 오류를 재현·수정했다. 정상 교훈과 원본 기록을 보존하고 invalidRecords로 표시한다. 최근 반환 3개 밖의 동일 목적 충돌 후보도 최근 24개 검사 범위 안에서 확인한다. 다른 목적은 추가 파일 조회를 생략한다. 자연어 의미 충돌 자동 탐지는 제공하지 않는다.
3. 복구: 부분 저장 재시도, 중복 차단, 동시 잠금, 용량 초과, 승인 만료, 아카이브 손상·경로 이탈·쓰기 실패 시험 통과. 한도 자동 갱신이나 임의 잠금 해제는 하지 않는다.
4. 회귀: npm run validate, npm test 전체 18개 스크립트 통과. 작업 학습 48개 그룹, bridge 26개 그룹, MCP 19개 그룹. node --check로 수정한 런타임 2개 문법 확인. 최초 손상 교훈 재현 시험 실패와 중간 조회 횟수 회귀 실패를 수정 후 다시 검증했다. 별도 lint/typecheck/build 스크립트는 없다.

## 파일과 설치
변경: plugins/autonomy-team/runtime/bridge.mjs, plugins/autonomy-team/runtime/learning.mjs, test/work-learning.mjs 및 이 보고서. 런타임 수정 파일 2개를 기존 CLI·Desktop 설치 경로에 백업 후 동기화하고 바이트 일치를 확인한다. 설정·훅 정의·신뢰 승인·다른 플러그인은 변경하지 않는다.

## 증거와 제한
시험의 syntheticEvents/realModelExecution=false는 그대로 유지했다. 시험 데이터를 실제 업무 성공 경험으로 저장하지 않았다. 이번 요청의 실제 turnKey로 시작한 작업에서 기존 Desktop MCP 호출이 runtime-source-changed로 실패해 CLI 대체 경로를 사용했다. 이번 작업은 보수적으로 unverified로 종료하고 성공 교훈을 만들지 않는다. 이미 반환된 실제 교훈의 원본 보존·계획과 효과 구분 규칙은 검토에 적용했다.

남은 작업은 기존 Desktop MCP 재연결이다. 다른 세션 작업을 저장한 뒤 앱을 완전히 종료하고 재실행해야 새 프로세스에 최신 코드가 적용된다. 이후 sourceStatus=current와 승인 유효 여부를 확인하고, 실제 업무의 자동 호출·저장·후속 재사용·역할 개선 효과를 관찰한다. 새 로컬 MCP 성공이 기존 Desktop 재연결 성공을 의미하지 않는다. 장기 효과는 실제 업무 누적 후 판단한다. 이번 검수는 무오류 보장이나 전체 공개 배포 승인이 아니다.
