# SoDam 자동 운영 요구 대조 및 정본 보완 검증

검사일: 2026-10-12 (한국 시간). 범위: 이번에 직접 읽은 정본 런타임·설정·테스트 및 연결된 MCP 진단. 접근 가능한 사실을 확인했으며 모든 과거 채팅·호스트 내부 원인을 전수 확인한 것으로 주장하지 않는다.

## 목표와 보존 범위

새 채팅에서 다른 프로젝트·다른 업무를 맡겨도 업무 수행, 검증된 절차 저장, 관련 절차 재사용, 필요한 역할 생성·개선·비활성화·복귀가 자동으로 연결되는 것이 목표다. 같은 프로젝트의 연속성만으로 완료를 판단하지 않는다. 모델 가중치 학습이 아닌 절차 기반 학습이다. 예약 작업을 만들지 않았다.

개발 변경은 SoDam-Agent-Codex 정본에만 적용했다. D 테스트 복사본은 검증 기록 저장 대상으로 유지했다. 실제 승인 등록·공유 동의·설치 캐시·Codex 설정·AGENTS.md·개인 기억은 변경하지 않았다. 시험이 만든 HOME·작업 공간은 격리된 임시 데이터다.

## 확인한 문제와 근거

| 항목 | 직접 확인한 근거 | 판정과 조치 |
| --- | --- | --- |

| 모든 새 채팅·업무 지원 | 저장된 Desktop 프로젝트 목록에 D 테스트 프로젝트가 없음. 정본 문서도 프로젝트 없는 채팅의 자동 저장 위치와 공통 역할 운영을 미완료로 명시 | 현재 도구로 D 작업 위치의 새 채팅을 정확히 생성·연결했다는 주장은 하지 않음 |

이 보완은 제외 처리의 실제 코드 결함을 해결한다. 전달 식별자 누락·모든 새 채팅 자동 운영·전역 역할 관리 문제 전체를 해결한 것은 아니다.

## 재현, 수정, 재검증

1. 기존 구현을 읽어 MCP skip 누락 및 반복 skip 실패 조건을 확인했다.
2. 고정 연산을 추가했다. 실제 등록된 턴·기존 승인·상태 검사는 그대로 적용하며 자유 명령 실행이나 권한 생성 기능은 추가하지 않았다.
3. 오입력, 없는 턴, 중복 호출, 닫힌 턴, 시작된 업무, 실패 사건, user-stop, 경험 보존과 실제 stdio 호출 시험을 추가했다.
4. 추가 테스트 변수명 충돌과 패치 문자열 치환 오류가 실행에서 발견됐다. 해당 오류를 수정하고 다시 검사했다. 실패를 통과로 취급하지 않았다.
5. 기존 전체 테스트를 다시 실행하여 통과했다.

## 보안과 데이터 보존

전체 시험에 경로 탈출, 링크·하드링크, 만료 승인, 한도, 잘못된 입력, 실패/unknown 판정, 오류 응답의 입력 미반사, 대표 비밀 값 차단, 증거 변경, 역할 변조, 회귀 및 복귀 검사가 포함됐다. 실제 비밀 값을 테스트에 넣지 않았다. 기존 기능·실패 검사·권한 검사를 무력화하지 않았다. 원문을 교훈으로 복사하지 않았다.

이번 코드 수정 범위의 검사를 수행했으며 전체 저장소·과거 로그·모든 빌드물의 민감정보 전수 검사나 법적 권리 검사를 완료한 것으로 주장하지 않는다. 브라우저 화면·모바일 반응형·웹 로그인·외부 DB CRUD는 이번 고정 런타임 변경의 검증 범위가 아니며 미실행이다.

## 남은 단계와 완료 기준

1. 관리 변경이 허용되는 실행 맥락에서 변경된 훅 정의와 설치 절차를 검토한 뒤 정본을 설치본에 반영한다. 이미 승인한 공유에 다시 동의를 요구할 이유는 없지만, 활성화 전 런타임 호환을 확인해야 한다.
2. 실제 연결 MCP의 지문이 정본과 일치하고 새 스키마를 노출하는지 확인한다. 정본 변경 없는 반복 재시작으로 대체하지 않는다.
3. 기존 D 승인 범위·만료·한도를 유지하면서 별도 절차 공유를 활성화한다. 구 승인 등록 파일을 바꾸지 않는다.
4. 서로 다른 승인 프로젝트의 새 요청에서 신뢰된 시작 사건, 실제 산출물, 검증된 절차 저장, 다음 별도 요청의 관련 절차 반환과 실제 적용을 각각 대조한다. 테스트용 업무는 파일 작업 검증에 유효하나 실제 장기 성과라고 부르지 않는다.
5. 역할 생성 필요가 실제로 관찰되면 기존 역할 재사용을 먼저 확인한다. 새 역할은 한도 내 후보·시험 적용·짝지은 평가·비활성화·복귀 검증을 거친다. 역할 파일 생성만으로 실행·개선 효과를 선언하지 않는다.
6. 직접 입력 성공과 채팅 도구 전송 문제는 별도 판정한다. 호스트가 시작 식별자를 제공하지 않는 경로를 가짜 자동 시작 기록으로 보충하지 않는다.

현재 완료: 정본 최소 보완 및 기술 회귀 검사. 미완료: 설치 반영, 실제 공유 활성화, 서로 다른 새 채팅의 실제 자동 호출·학습 재사용·역할 운영 검증. 장기 개선 효과는 업무 누적 후 판단한다.
